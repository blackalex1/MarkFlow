# Тест выпадающих списков (Dropdowns)

Этот файл проверяет поддержку новых интерактивных выпадающих блоков `@dropdown`.

## 1. Базовый пример

@dropdown Нажми на меня, чтобы увидеть секрет
Поздравляю! Ты раскрыл этот блок. Здесь может быть любой контент.
- Список раз
- Список два
@enddropdown

## 2. Сложный контент внутри

@dropdown Код и цитаты
Ниже приведен пример кода:

```python
def example():
    return "Dropdowns are cool!"
```

> [!TIP]
> Колл-ауты тоже отлично работают внутри выпадающих списков.
@enddropdown

@enddropdown

## 4. Интеграция с вкладками (Вложенность)

@dropdown Вкладки внутри выпадающего списка

@enddropdown
