# Тестовые вкладки

Пример использования вкладок с различным контентом.

@tabs
@tab Предупреждение
> [!WARNING]
> Будьте осторожны! Это тестовое предупреждение внутри вкладки.
> Оно должно отображаться в желтом блоке.

@tab Текст
В этой вкладке просто обычный текст. 
Маркдаун позволяет форматировать его **жирным**, *курсивом* или создавать списки:
- Первый пункт
- Второй пункт
- Третий пункт

@tab Код
Ниже приведен пример кода на Python:

```python
def hello_world():
    print("Hello from MarkFlow tabs!")
    
for i in range(5):
    print(f"Index: {i}")
```
@endtabs
